# Reports and Analysis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every new sale and commission income stores its lines and sale time, and a rewritten Reports page shows what sells best, how a market day went, how the money develops and where stock and production stand, for a chosen period.

**Architecture:**
- Pure rules live in `utils/reports/` and are unit-tested with `node:test` against one fixed shop history (`tests/fixtures/reports.js`, built with local `Date` constructors so it reads the same in every time zone): `common.js` (cents, times, sale helpers), `period.js`, `lines.js` (`saleLines`, `commissionLines`), `sales.js`, `marketDay.js`, `money.js`, `stock.js`, `csv.js`.
- Checkout (`pages/catalog.vue`) and the commission delivery (`components/CommissionSheet.vue`) pass `items` and `sold_at` to `addTransaction`; `postTransaction` sends them, the offline queue keeps them (it stores the whole transaction), and `fromRecord` keeps `items`, `sold_at` and `created` on cached entries.
- The migration adds `items` (json) and `sold_at` (date) to `budget_tracker_transactions` in the same `addFields` op as a missing `date`.
- `composables/useReportData.js` loads articles, categories, deals, commissions and the period's stock movements (plus the last 30 days) and tolerates 403/404; offline it sets `needsConnection`. `pages/reports.vue` computes every tab's figures from it and from `useTransactions().transactions`, and hands them to four presentational tab components and two plain SVG charts. Export writes the current tab's table as CSV.

**Tech Stack:** Nuxt 3.21 / Vue 3.5 `<script setup>`, Tailwind 3.4 semantic tokens (`fill-*` / `stroke-*` work with them out of the box), PocketBase 0.22 with `pocketbase@0.21.5`, `node:test`, Playwright against the in-memory fake PocketBase.

**Spec:** `docs/superpowers/specs/2026-10-14-reports-design.md`

## Global Constraints

- **Sale lines (`items`)**, one per line: `{ article, name, category, categoryName, quantity, unitPrice, lineTotal, discount, deal, dealName }`. Euros as numbers, computed in whole cents. `deal` / `dealName` are the applied deal's id and name, `''` without one (see Decisions).
- **Invariant:** Σ `lineTotal` − Σ `discount` = `amount`, to the cent. A cart's discounts add up to its deal savings; each applied deal's saving is spread over its own lines in proportion to their `lineTotal`, the rounding remainder on that deal's last line. A commission's agreed price is spread over its lines in proportion to list value, the remainder on the last line.
- **`sold_at`:** an ISO time (`new Date().toISOString()`), set when the sale is made, never when it syncs.
- **Data model (`budget_tracker_transactions`):** `items` `{ type: 'json', options: { maxSize: 2000000 } }` and `sold_at` `{ type: 'date', options: { min: '', max: '' } }`, both optional. Rules unchanged. Schema writes keep `MIGRATION_GAP_MS = 1500`.
- **Local time:** a day is the device's local calendar day. Weeks start on Monday. Ranges are `{ start, end }` local midnights with `end` exclusive. Build test dates with local constructors (`new Date(2026, 9, 14, 13, 0)`); unit tests must pass under `TZ=Pacific/Auckland` too.
- **Money** is computed in cents and displayed with `formatCurrency()`. Expenses (negative amounts) appear only on the Money tab.
- **Strings (verbatim from the spec):**
  - period chips `Today` · `Week` · `Month` · `Year` · `Custom`; report chip group labelled `Report` with `Sales` · `Market day` · `Money` · `Stock`
  - `N older sales aren't split by article` (N is the count, the rest verbatim)
  - `Needs a connection`
  - `~N days`
  - section titles `Top articles`, `Top categories`, `Deals used`, `Runs out soonest`, `Printed vs sold`, `Commissions`, `Stock value`
  - the action `Export`
- **Removed:** the old KPI tiles, trend placeholders, "Expenses by Category", "Top Expense Categories" and the sample "Recent Transactions" on `/reports`. The page keeps its title `Financial Reports` (checked by `tests/e2e/navigation.spec.js`) and the period group label `Time period`.
- **Conventions:**
  - Vue 3 `<script setup>`; 2-space indent, single quotes, no semicolons; imports ordered Vue, components, composables, utilities.
  - Semantic colour tokens only (`surface`, `card`, `muted`, `line`, `ink`, `ink-muted`, `accent`, `income`, `expense`, also as `fill-*` / `stroke-*`); no raw gray/blue classes, no `dark:` classes, no `darkMode` ternaries. `tests/unit/no-raw-colours.test.js` checks every `.vue` file under `components/` and `pages/`.
  - 44px tap targets; every page works at 375px with no horizontal scroll.
  - `gotoReady` in e2e; `formatCurrency` for money; data access through the PocketBase SDK and the existing composables.
- **Never:**
  - stop the `nuxt dev` server on :3000 (if new Tailwind classes do not apply, `touch tailwind.config.js`);
  - contact pocket.lasseharm.space;
  - run `pb:migrate` in any form, with or without flags;

## Review Focus

1. **A cart mixing two deals, an overridden article and a line without a deal** must still store lines whose Σ `lineTotal` − Σ `discount` equals the posted amount to the cent, with no negative discount. *Pinned in Task 1: "every cart of up to 5 keychains, 3 figures and 3 coasters adds up to its total", and Task 3: "a checkout posts its lines and sale time, and the lines add up to the amount".*
2. **Sale movements of sales that already have lines** must not be counted a second time as "older sale" units, even when the phone's clock runs ahead of the server (the cut-off is the first line sale's server `created`, not its `sold_at`). *Pinned in Task 4: "movements after the first sale with lines are not counted twice".*
3. **A sale made offline** keeps its lines and the time it was made through the queue, and posts them when it syncs; PocketBase's empty `null` / `''` values on older records read as "no lines". *Pinned in Task 3: "an offline checkout syncs its stock changes later" (extended) and "fromRecord keeps the sale lines, the sale time and the created stamp for the reports".*
4. **A device far from UTC or across a daylight-saving change** (Auckland, the last week of October in Europe) still puts sales on the right local day, week and hour. *Pinned in Task 1 and Task 4 by running the unit suite with `TZ=Pacific/Auckland`, and by "a month is cut into weeks from Monday, the first one starting with the month" (DST week).*
5. **A server that is not fully migrated** (`deals` missing → 404, `commissions` still locked → 403) shows the reports with those parts empty instead of an error. *Pinned in Task 5: "a locked or missing collection reports as empty instead of failing".*

## Decisions the spec leaves open

1. **Deal attribution.** The spec's line shape cannot say which deal a discount came from, and reading descriptions is ruled out, so every line also carries `deal` (id) and `dealName` (`''` without a deal). "Deals used" counts a deal once per sale and shows its current name, else the stored one.
2. **Commission lines.** `lineTotal` is the line's share of the agreed price; the weights are current list price × quantity (by quantity when no line has a price, e.g. every article archived); `unitPrice` = share ÷ quantity rounded to the cent; `discount` 0.
3. **Older-sale units** are sale movements created before the first sale with lines reached the server (its `created`), plus the units noted as `oversold by N`. Without any line sale every sale movement counts.
4. **Japan** is 10% of the period's income, as the spec says (the dashboard's Japan is 10% of the balance); its tile reads `Japan (10% of income)`.
5. **Periods** are the calendar day/week/month/year containing today; Custom includes both ends, swaps a reversed range and treats a missing day as today. Defaults: `Month` and `Sales`.
6. **Market day** lists the market days inside the selected period (newest first, default the latest); the comparison looks at the up to 5 market days before it in the whole history. Averages are the mean of the per-day values; older days without lines count 0 items. Offline it shows `Needs a connection`, as the spec lists it with the server tabs.
7. **Money:** week buckets are labelled with their first day (`5 Oct`), months as `Oct 2026`; the first bucket starts with the range. The running balance includes everything before the period, so its last point is the balance at the end of the period.
8. **Runs out soonest:** `Math.round(stock ÷ (units sold in the last 30 × 24 h ÷ 30))`; an article sold out with recent sales shows `~0 days`.
9. **Export:** Sales → top articles (`Article,Units,Revenue`), Market day → the chosen day per hour (`Day,Hour,Takings`), Money → buckets with balance, Stock → printed vs sold. File `report-<tab>-<first day>-<last day>.csv`; money with two decimals and a dot. Export is disabled while a server tab shows no figures.
10. **Copy the spec does not give** (kept short): empty states `No sales in this period`, `No market days in this period`, `No transactions in this period`, `Nothing printed or sold in this period`, `No sales in the last 30 days`, `No deals used in this period`, `No earlier market days to compare with`; labels `Sort by` (`Revenue` / `Units`), `Market day`, `Takings`, `Items sold`, `Sales`, `Average sale`, `Income`, `Expenses`, `Profit`, `Balance`, `Breakdown`, `Per week` / `Per month`, `Open value`, `Delivered value`, `Average days to deliver`; `Loading report...`; error `Could not load the report. Check your connection and try again.`; units of a category without a known category group under `Other`.
11. **Manual transactions** (the dashboard form, orphan uploads of old entries) get no `items` and no `sold_at`: the spec names the checkout and the commission income only, and an uploaded old entry must not be stamped with today's time.

### Task 1: Period rules and sale lines

**Files:**
- Create: `utils/reports/common.js`, `utils/reports/period.js`, `utils/reports/lines.js`
- Test: `tests/unit/reports-period.test.js`, `tests/unit/reports-lines.test.js`

**Interfaces:**
- Consumes: `priceCart(lines, deals)` (`utils/deals.js`; returns `{ lines: [{ ...cartLine, unitPrice, lineTotal }], applied: [{ dealId, name, saving, description }], subtotal, savings, total }`, euros), `itemsOf(commission, articles)` (`utils/commissions.js`), `effectivePrice(article, category)` (`utils/pricing.js`), `localDate(date)` (`utils/transactions.js`).
- Produces (`utils/reports/common.js`):
  - `toCents(value)` → integer cents; `toEuros(cents)` → number
  - `toDate(value)` → `Date | null` (`'YYYY-MM-DD'` = local midnight; ISO or PocketBase `'YYYY-MM-DD HH:MM:SS.sssZ'` = that instant)
  - `isIncome(transaction)`, `linesOf(transaction)` → array (never null), `hasLines(transaction)`
  - `saleTime(transaction)` → `Date | null` (`sold_at`, else `created`)
  - `lineCents(line)` → cents of `lineTotal − discount`
  - `soldUnits(movement)` → units of a `sale` movement (`−change` + `oversold by N`), 0 otherwise
- Produces (`utils/reports/period.js`):
  - `PERIODS` = `[{ value: 'today'|'week'|'month'|'year'|'custom', label }]`
  - `periodRange(kind, now = new Date(), custom = {})` → `{ start: Date, end: Date }` (custom `{ from, to }` as `'YYYY-MM-DD'`)
  - `inPeriod(dateOrIso, range)` → boolean; `daysIn(range)` → number; `addDays(date, days)` → Date
  - `bucketFor(kind, range)` → `'week' | 'month'`; `rangeDays(range)` → `{ first, last }` as `'YYYY-MM-DD'`
- Produces (`utils/reports/lines.js`):
  - `spread(totalCents, weights)` → integer cents per weight, adding up to `totalCents`
  - `saleLines(pricedCart, deals)` → `items` for a checkout (cart lines may carry `categoryName`)
  - `commissionLines(commission, articles)` → `items` for a delivered commission (articles with `expand.category`)

```js
import { test } from 'node:test'
import assert from 'node:assert/strict'
import { localDate } from '../../utils/transactions.js'
import { toDate, saleTime, soldUnits, lineCents, linesOf } from '../../utils/reports/common.js'
import { PERIODS, periodRange, inPeriod, daysIn, bucketFor, rangeDays, addDays } from '../../utils/reports/period.js'

// Built with the local constructor: the same wall-clock times in every time zone
const NOW = new Date(2026, 9, 14, 13, 0) // Wednesday 14 October 2026, 13:00
const stamp = date => date.toISOString().replace('T', ' ')
const days = range => [localDate(range.start), localDate(range.end)]

test('the period picker offers Today, Week, Month, Year and Custom', () => {
  assert.deepEqual(PERIODS.map(period => period.label), ['Today', 'Week', 'Month', 'Year', 'Custom'])
})

test('today, week, month and year are local calendar ranges with an exclusive end', () => {
  assert.deepEqual(days(periodRange('today', NOW)), ['2026-10-14', '2026-10-15'])
  assert.deepEqual(days(periodRange('week', NOW)), ['2026-10-12', '2026-10-19'])
  assert.deepEqual(days(periodRange('month', NOW)), ['2026-10-01', '2026-11-01'])
  assert.deepEqual(days(periodRange('year', NOW)), ['2026-01-01', '2027-01-01'])
  const { start, end } = periodRange('week', NOW)
  assert.deepEqual([start.getHours(), start.getMinutes(), end.getHours()], [0, 0, 0])
})

test('a week runs Monday to Sunday, also on its first and last day', () => {
  assert.deepEqual(days(periodRange('week', new Date(2026, 9, 12, 0, 0))), ['2026-10-12', '2026-10-19'])
  assert.deepEqual(days(periodRange('week', new Date(2026, 9, 18, 23, 59))), ['2026-10-12', '2026-10-19'])
  // Across a month and a year end
  assert.deepEqual(days(periodRange('week', new Date(2026, 11, 31, 9))), ['2026-12-28', '2027-01-04'])
  assert.deepEqual(days(periodRange('month', new Date(2026, 11, 31, 9))), ['2026-12-01', '2027-01-01'])
})

test('a custom range includes its last day, swaps a reversed range and falls back to today', () => {
  assert.deepEqual(days(periodRange('custom', NOW, { from: '2026-10-01', to: '2026-10-03' })), ['2026-10-01', '2026-10-04'])
  assert.deepEqual(days(periodRange('custom', NOW, { from: '2026-10-03', to: '2026-10-01' })), ['2026-10-01', '2026-10-04'])
  assert.deepEqual(days(periodRange('custom', NOW, { from: '', to: 'nonsense' })), ['2026-10-14', '2026-10-15'])
  assert.deepEqual(days(periodRange('custom', NOW)), ['2026-10-14', '2026-10-15'])
  assert.throws(() => periodRange('decade', NOW), /Unknown period: decade/)
})

test('inPeriod reads day strings, ISO times, PocketBase stamps and dates', () => {
  const week = periodRange('week', NOW)
  assert.equal(inPeriod('2026-10-12', week), true)
  assert.equal(inPeriod('2026-10-18', week), true)
  assert.equal(inPeriod('2026-10-19', week), false)
  assert.equal(inPeriod('2026-10-11', week), false)
  assert.equal(inPeriod(stamp(new Date(2026, 9, 18, 23, 59)), week), true)
  assert.equal(inPeriod(stamp(new Date(2026, 9, 19, 0, 0)), week), false)
  assert.equal(inPeriod(new Date(2026, 9, 12, 0, 0).toISOString(), week), true)
  assert.equal(inPeriod(new Date(2026, 9, 11, 23, 59), week), false)
  assert.equal(inPeriod('', week), false)
  assert.equal(inPeriod(undefined, week), false)
  assert.equal(inPeriod('not a date', week), false)
})

test('days, money buckets and file-name days follow the calendar', () => {
  assert.equal(daysIn(periodRange('month', NOW)), 31)
  // October holds a daylight-saving change in many zones; counting by date ignores it
  assert.equal(daysIn(periodRange('custom', NOW, { from: '2026-10-20', to: '2026-10-30' })), 11)
  assert.equal(bucketFor('year', periodRange('year', NOW)), 'month')
  assert.equal(bucketFor('month', periodRange('month', NOW)), 'week')
  assert.equal(bucketFor('custom', periodRange('custom', NOW, { from: '2026-01-01', to: '2026-03-31' })), 'week')
  assert.equal(bucketFor('custom', periodRange('custom', NOW, { from: '2026-01-01', to: '2026-04-01' })), 'month')
  assert.deepEqual(rangeDays(periodRange('month', NOW)), { first: '2026-10-01', last: '2026-10-31' })
  assert.equal(localDate(addDays(new Date(2026, 9, 31), 1)), '2026-11-01')
})

test('toDate and saleTime read the times the app and PocketBase write', () => {
  assert.equal(toDate('2026-10-14').getTime(), new Date(2026, 9, 14).getTime())
  assert.equal(toDate('2026-10-14 08:30:00.000Z').toISOString(), '2026-10-14T08:30:00.000Z')
  assert.equal(toDate('2026-10-14T08:30:00.000Z').toISOString(), '2026-10-14T08:30:00.000Z')
  assert.equal(toDate(''), null)
  assert.equal(toDate(null), null)
  assert.equal(toDate('garbage'), null)
  const sold = new Date(2026, 9, 14, 10, 30)
  const created = new Date(2026, 9, 14, 10, 31)
  assert.equal(saleTime({ sold_at: sold.toISOString(), created: stamp(created) }).getTime(), sold.getTime())
  assert.equal(saleTime({ sold_at: '', created: stamp(created) }).getTime(), created.getTime())
  assert.equal(saleTime({ date: '2026-10-14' }), null)
})

  assert.equal(lineCents({ lineTotal: 0.3, discount: 0.1 }), 20)
  assert.deepEqual(linesOf({ items: null }), [])
```

Create `tests/unit/reports-lines.test.js`:

```js
import { test } from 'node:test'
import assert from 'node:assert/strict'
import { priceCart } from '../../utils/deals.js'
import { spread, saleLines, commissionLines } from '../../utils/reports/lines.js'

const CATEGORIES = {
  key: { id: 'cat-keychain', name: 'Keychain', base_price: 4 },
  fig: { id: 'cat-figure', name: 'Big Figure', base_price: 30 },
  big: { id: 'cat-big', name: 'Walldisplay', base_price: 35 },
  coaster: { id: 'cat-coaster', name: 'Coaster', base_price: 8 }
}
const DEALS = [
  { id: 'd-key', name: 'Keychain 2 for 7', type: 'bundle', categories: ['cat-keychain'], min_qty: 2, price: 7 },
  { id: 'd-big', name: 'Big items', type: 'group', categories: ['cat-figure', 'cat-big'], min_qty: 2, price: 25 },
  { id: 'd-coaster', name: 'Coaster 2 for 15', type: 'bundle', categories: ['cat-coaster'], min_qty: 2, price: 15 }
]

// A cart line as pages/catalog.vue builds it, including the category name
const cartLine = (id, category, quantity, override = 0) => ({
  articleId: id,
  name: `Article ${id}`,
  quantity,
  categoryId: category.id,
  categoryName: category.name,
  basePrice: category.base_price,
  override
})
const cents = value => Math.round(value * 100)
const sumCents = (lines, key) => lines.reduce((sum, line) => sum + cents(line[key]), 0)

test('spread keeps proportions, rounds down and puts the remainder on the last share', () => {
  assert.deepEqual(spread(1000, [1, 1, 1]), [333, 333, 334])
  assert.deepEqual(spread(1500, [3000, 3500]), [692, 808])
  assert.deepEqual(spread(1, [1, 1, 0]), [0, 0, 1])
  assert.deepEqual(spread(0, [5, 5]), [0, 0])
  assert.deepEqual(spread(700, [0, 0]), [350, 350])
  assert.deepEqual(spread(500, []), [])
})

test('a keychain bundle puts its saving on the keychain line', () => {
  const priced = priceCart([cartLine('k1', CATEGORIES.key, 3)], DEALS)
  assert.deepEqual(saleLines(priced, DEALS), [{
    article: 'k1',
    name: 'Article k1',
    category: 'cat-keychain',
    categoryName: 'Keychain',
    quantity: 3,
    unitPrice: 4,
    lineTotal: 12,
    discount: 1,
    deal: 'd-key',
    dealName: 'Keychain 2 for 7'
  }])
})

test('a group deal spreads its saving over its lines by their totals, the remainder on the last', () => {
  const priced = priceCart([cartLine('f1', CATEGORIES.fig, 1), cartLine('w1', CATEGORIES.big, 1)], DEALS)
  assert.equal(priced.total, 50)
  const lines = saleLines(priced, DEALS)
  assert.deepEqual(lines.map(line => [line.lineTotal, line.discount, line.dealName]), [[30, 6.92, 'Big items'], [35, 8.08, 'Big items']])
  assert.equal(sumCents(lines, 'lineTotal') - sumCents(lines, 'discount'), cents(priced.total))
})

test('two deals, an overridden article and a line without a deal add up to the cart total', () => {
  const priced = priceCart([
    cartLine('k1', CATEGORIES.key, 2),
    cartLine('k2', CATEGORIES.key, 1),
    cartLine('f1', CATEGORIES.fig, 1),
    cartLine('f2', CATEGORIES.fig, 1, 45),
    cartLine('w1', CATEGORIES.big, 1),
    cartLine('c1', CATEGORIES.coaster, 1)
  ], DEALS)
  const lines = saleLines(priced, DEALS)
  assert.deepEqual(lines.map(line => [line.article, line.discount, line.deal]), [
    ['k1', 0.66, 'd-key'],
    ['k2', 0.34, 'd-key'],
    ['f1', 6.92, 'd-big'],
    // An overridden article never takes part in a deal
    ['f2', 0, ''],
    ['w1', 8.08, 'd-big'],
    // One coaster does not reach its bundle
    ['c1', 0, '']
```

```js
// Shared rules for the reports: money in whole cents, PocketBase times, sales and their lines
export const toCents = value => Math.round(Number(value) * 100)
export const toEuros = cents => cents / 100

const DAY = /^(\d{4})-(\d{2})-(\d{2})$/

// 'YYYY-MM-DD' is a local calendar day (its local midnight). Anything else is a point in time:
// ISO ('…T…Z') or PocketBase's 'YYYY-MM-DD HH:MM:SS.sssZ'. Returns null for empty or unreadable values.
export function toDate (value) {
  if (value instanceof Date) return Number.isNaN(value.getTime()) ? null : value
  if (!value) return null
  const day = String(value).match(DAY)
  const date = day
    ? new Date(Number(day[1]), Number(day[2]) - 1, Number(day[3]))
    : new Date(String(value).replace(' ', 'T'))
  return Number.isNaN(date.getTime()) ? null : date
}

// Expenses are negative amounts and never count as sales
export const isIncome = transaction => Number(transaction.amount) > 0
// PocketBase returns an empty json field as null; entries from before line data have no items at all
export const linesOf = transaction => (Array.isArray(transaction?.items) ? transaction.items : [])
export const hasLines = transaction => linesOf(transaction).length > 0
// When the sale happened: sold_at, else the record's created stamp; null for entries with neither
export const saleTime = transaction => toDate(transaction.sold_at) ?? toDate(transaction.created)
// A line's takings: its total less its share of the deal savings
export const lineCents = line => toCents(line.lineTotal) - toCents(line.discount)

const OVERSOLD = /oversold by (\d+)/
// Units a sale movement stands for: what left stock plus what was oversold (stock stops at 0, the rest is noted)
export const soldUnits = movement => (movement.reason === 'sale'
  ? -Number(movement.change) + Number(String(movement.note ?? '').match(OVERSOLD)?.[1] ?? 0)
  : 0)
```

```js
// Report periods in the device's local time. See docs/superpowers/specs/2026-10-14-reports-design.md
import { localDate } from '../transactions.js'
import { toDate } from './common.js'

export const PERIODS = [
  { value: 'today', label: 'Today' },
  { value: 'week', label: 'Week' },
  { value: 'month', label: 'Month' },
  { value: 'year', label: 'Year' },
  { value: 'custom', label: 'Custom' }
]

const DAY_MS = 86_400_000
const ISO_DAY = /^\d{4}-\d{2}-\d{2}$/

// Calendar arithmetic through the local constructor, so a daylight-saving change never shifts a day
export const addDays = (date, days) => new Date(date.getFullYear(), date.getMonth(), date.getDate() + days)
const midnight = date => addDays(date, 0)
const customDay = value => (ISO_DAY.test(String(value ?? '')) ? toDate(value) : null)

// { start, end } as local midnights, end exclusive. Weeks start on Monday. Custom takes { from, to }
// as 'YYYY-MM-DD' with `to` included; a missing day counts as today and a reversed range is swapped.
export function periodRange (kind, now = new Date(), custom = {}) {
  const today = midnight(now)
  if (kind === 'today') return { start: today, end: addDays(today, 1) }
  if (kind === 'week') {
    const start = addDays(today, -((today.getDay() + 6) % 7))
    return { start, end: addDays(start, 7) }
  }
  if (kind === 'month') {
    return { start: new Date(today.getFullYear(), today.getMonth(), 1), end: new Date(today.getFullYear(), today.getMonth() + 1, 1) }
  }
  if (kind === 'year') return { start: new Date(today.getFullYear(), 0, 1), end: new Date(today.getFullYear() + 1, 0, 1) }
  if (kind === 'custom') {
    const from = customDay(custom.from) ?? today
    const to = customDay(custom.to) ?? today
    const [first, last] = from <= to ? [from, to] : [to, from]
    return { start: first, end: addDays(last, 1) }
  }
  throw new Error(`Unknown period: ${kind}`)
}

// A day string, ISO time, PocketBase stamp or Date; unreadable values are outside every period
export function inPeriod (value, range) {
  const date = toDate(value)
  return !!date && date >= range.start && date < range.end
}

// Calendar days in the range, counted by date so a daylight-saving change does not matter
const dayNumber = date => Date.UTC(date.getFullYear(), date.getMonth(), date.getDate()) / DAY_MS
export const daysIn = range => dayNumber(range.end) - dayNumber(range.start)

// Money buckets: months for a year or a custom range longer than 90 days, weeks otherwise
export const bucketFor = (kind, range) => (kind === 'year' || (kind === 'custom' && daysIn(range) > 90) ? 'month' : 'week')

// First and last day as 'YYYY-MM-DD', for file names
export const rangeDays = range => ({ first: localDate(range.start), last: localDate(addDays(range.end, -1)) })
```

```js
// The `items` a sale or a delivered commission stores on its transaction, all in whole cents.
// See docs/superpowers/specs/2026-10-14-reports-design.md, criterion 1
import { itemsOf } from '../commissions.js'
import { effectivePrice } from '../pricing.js'
import { toCents, toEuros } from './common.js'

// Splits totalCents in proportion to the weights, rounding each share down; the remainder goes on the
// last share, so the shares always add up to the total. Without any weight it splits evenly.
export function spread (totalCents, weights) {
  if (!weights.length) return []
  const sum = weights.reduce((acc, weight) => acc + weight, 0)
  const basis = sum > 0 ? weights : weights.map(() => 1)
  const basisSum = sum > 0 ? sum : weights.length
  const shares = basis.map(weight => Math.floor(totalCents * weight / basisSum))
  shares[shares.length - 1] += totalCents - shares.reduce((acc, share) => acc + share, 0)
  return shares
}

const regularIn = deal => line =>
  !(Number(line.override) > 0) && line.quantity > 0 && (!deal || deal.categories.includes(line.categoryId))

// One line per cart line. Each applied deal's saving is spread over the lines it covered (the regular
// lines of its categories, as priceCart counts them) in proportion to their totals, the remainder on the
// deal's last line. So Σ lineTotal − Σ discount = the cart total, to the cent.
export function saleLines (pricedCart, deals = []) {
  const discounts = pricedCart.lines.map(() => 0)
  const dealOf = pricedCart.lines.map(() => null)
  for (const applied of pricedCart.applied) {
    // The deal always comes from `deals`; were it missing, its saving still lands on the regular lines
    const deal = deals.find(item => item.id === applied.dealId)
    const members = pricedCart.lines.map((line, index) => ({ line, index })).filter(({ line }) => regularIn(deal)(line))
    const shares = spread(toCents(applied.saving), members.map(({ line }) => toCents(line.lineTotal)))
    members.forEach(({ index }, i) => {
      discounts[index] += shares[i]
      dealOf[index] = applied
    })
  }
  return pricedCart.lines.map((line, index) => ({
    article: line.articleId,
    name: line.name,
    category: line.categoryId ?? '',
    categoryName: line.categoryName ?? '',
    quantity: line.quantity,
    unitPrice: line.unitPrice,
    lineTotal: line.lineTotal,
    discount: toEuros(discounts[index]),
    deal: dealOf[index]?.dealId ?? '',
    dealName: dealOf[index]?.name ?? ''
  }))
}

// The agreed price spread over the commission's lines in proportion to their list value (current price
// × quantity), the rounding remainder on the last line. An article that is gone has no price; when no
// line has one, the price is spread by quantity.
export function commissionLines (commission, articles = []) {
  const lines = itemsOf(commission, articles)
  const found = lines.map(line => articles.find(article => article.id === line.article))
  const listed = lines.map((line, i) => toCents(effectivePrice(found[i], found[i]?.expand?.category)) * Number(line.quantity))
  const weights = listed.some(value => value > 0) ? listed : lines.map(line => Number(line.quantity))
  const shares = spread(toCents(commission.agreed_price), weights)
  return lines.map((line, i) => ({
    article: line.article,
    name: line.name,
    category: found[i]?.category ?? '',
    categoryName: found[i]?.expand?.category?.name ?? '',
    quantity: Number(line.quantity),
    unitPrice: toEuros(Math.round(shares[i] / Math.max(1, Number(line.quantity)))),
    lineTotal: toEuros(shares[i]),
    discount: 0,
    deal: '',
    dealName: ''
  }))
}
```

```js
// Sales tab: what sells best in the period. Revenue comes from sale lines; units from lines plus, for
// older sales without lines, their stock movements.
import { UNKNOWN_ARTICLE } from '../commissions.js'
import { toCents, toEuros, toDate, isIncome, hasLines, linesOf, lineCents, saleTime, soldUnits } from './common.js'
import { inPeriod } from './period.js'

// Units whose category is unknown (a commission line for an article that was already gone) group here
export const OTHER_CATEGORY = 'Other'

const byRevenue = (a, b) => b.revenue - a.revenue || b.units - a.units || a.name.localeCompare(b.name)
const byUnits = (a, b) => b.units - a.units || b.revenue - a.revenue || a.name.localeCompare(b.name)
export const sortRows = (rows, key = 'revenue') => [...rows].sort(key === 'units' ? byUnits : byRevenue)

// Sale movements logged before the first sale with lines reached the server belong to older sales;
// later ones are already counted in lines. The record's created stamp is server time, like the movements'.
const lineDataStart = (transactions) => {
  const times = transactions.filter(hasLines).map(sale => toDate(sale.created) ?? saleTime(sale)).filter(Boolean)
  return times.length ? Math.min(...times.map(date => date.getTime())) : Infinity
}

export function salesSummary ({ transactions, movements = [], articles = [], categories = [], deals = [], range }) {
  const sales = transactions.filter(sale => isIncome(sale) && inPeriod(sale.date, range))
  const articleRows = new Map()
  const categoryRows = new Map()
  const dealRows = new Map()
  const categoryName = (id, fallback) => categories.find(category => category.id === id)?.name || fallback || OTHER_CATEGORY
  const add = (rows, id, name, cents, units) => {
    const row = rows.get(id) ?? { id, name, cents: 0, units: 0 }
    row.cents += cents
    row.units += units
    rows.set(id, row)
  }

  for (const sale of sales) {
    const counted = new Set()
    for (const line of linesOf(sale)) {
      const cents = lineCents(line)
      const units = Number(line.quantity)
      const name = articles.find(article => article.id === line.article)?.name ?? line.name ?? UNKNOWN_ARTICLE
      add(articleRows, line.article, name, cents, units)
      add(categoryRows, line.category || '', categoryName(line.category, line.categoryName), cents, units)
      if (!line.deal) continue
      // A deal counts once per sale, however many of its lines it covered. It is named as it is
      // called now, else as it was called at the sale.
      const dealName = deals.find(item => item.id === line.deal)?.name ?? line.dealName
      const deal = dealRows.get(line.deal) ?? { id: line.deal, name: dealName, times: 0, discountCents: 0 }
      deal.discountCents += toCents(line.discount)
      if (!counted.has(line.deal)) deal.times++
      counted.add(line.deal)
      dealRows.set(line.deal, deal)
    }
  }

  const start = lineDataStart(transactions)
  for (const movement of movements) {
    const at = toDate(movement.created)
    if (movement.reason !== 'sale' || !at || at.getTime() >= start || !inPeriod(at, range)) continue
    const article = articles.find(item => item.id === movement.article) ?? movement.expand?.article
    const units = soldUnits(movement)
    add(articleRows, movement.article, article?.name ?? UNKNOWN_ARTICLE, 0, units)
    add(categoryRows, article?.category || '', categoryName(article?.category, ''), 0, units)
  }

  const rows = map => sortRows([...map.values()].map(({ cents, ...row }) => ({ ...row, revenue: toEuros(cents) })))
  return {
    topArticles: rows(articleRows),
    topCategories: rows(categoryRows),
    deals: [...dealRows.values()]
      .map(({ discountCents, ...deal }) => ({ ...deal, discount: toEuros(discountCents) }))
      .sort((a, b) => b.times - a.times || b.discount - a.discount || a.name.localeCompare(b.name)),
    olderSalesCount: sales.filter(sale => !hasLines(sale)).length
  }
}
```

```js
// Market day tab: one day's takings, items and sales, per hour, against the market days before it
import { toCents, toEuros, isIncome, linesOf, saleTime } from './common.js'

// Local days ('YYYY-MM-DD') with at least one sale, newest first
export function marketDays (transactions) {
  return [...new Set(transactions.filter(isIncome).map(sale => sale.date).filter(Boolean))].sort().reverse()
}

const figuresFor = (transactions, day) => {
  const sales = transactions.filter(sale => isIncome(sale) && sale.date === day)
  return {
    sales,
    cents: sales.reduce((sum, sale) => sum + toCents(sale.amount), 0),
    // Items come from lines; sales from before line data add none
    items: sales.reduce((sum, sale) => sum + linesOf(sale).reduce((acc, line) => acc + Number(line.quantity), 0), 0)
  }
}

// perHour[h] holds the takings of local hour h, from sold_at or else created. A sale with neither
// (an old entry queued on this device) counts in the takings but in no hour.
export function dayReport ({ transactions, day }) {
  const { sales, cents, items } = figuresFor(transactions, day)
  const hours = Array(24).fill(0)
  for (const sale of sales) {
    const at = saleTime(sale)
    if (at) hours[at.getHours()] += toCents(sale.amount)
  }
  return { takings: toEuros(cents), items, sales: sales.length, perHour: hours.map(toEuros) }
}

// The hours to chart: first to last hour with takings, or 9 to 17 when no sale has a time
export function hourWindow (perHour) {
  const used = perHour.map((value, hour) => (value ? hour : -1)).filter(hour => hour >= 0)
  const [first, last] = used.length ? [used[0], used[used.length - 1]] : [9, 17]
  return Array.from({ length: last - first + 1 }, (_, i) => first + i)
}

const mean = values => values.reduce((sum, value) => sum + value, 0) / values.length
const averageSaleCents = figures => (figures.sales.length ? figures.cents / figures.sales.length : 0)

// The day minus the average of up to `count` market days before it: takings and average sale in
// euros, items to one decimal. null when there is no earlier market day.
export function compareWithPrevious ({ transactions, day, count = 5 }) {
  const previous = marketDays(transactions).filter(item => item < day).slice(0, count)
  if (!previous.length) return null
  const current = figuresFor(transactions, day)
  const past = previous.map(item => figuresFor(transactions, item))
  return {
    days: previous.length,
    takings: toEuros(Math.round(current.cents - mean(past.map(figures => figures.cents)))),
    items: Math.round((current.items - mean(past.map(figures => figures.items))) * 10) / 10,
    averageSale: toEuros(Math.round(averageSaleCents(current) - mean(past.map(averageSaleCents))))
  }
}
```

```js
// Money tab: income, expenses and profit per week or month, the running balance and the Japan share
import { toCents, toEuros, toDate } from './common.js'
import { addDays } from './period.js'

const MONTHS = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec']
const dayLabel = date => `${date.getDate()} ${MONTHS[date.getMonth()]}`
const monthLabel = date => `${MONTHS[date.getMonth()]} ${date.getFullYear()}`

// The range cut at each Monday (weeks) or each 1st (months); the first bucket starts with the range
export function buckets (range, bucket) {
  const list = []
  let start = range.start
  while (start < range.end) {
    const next = bucket === 'month'
      ? new Date(start.getFullYear(), start.getMonth() + 1, 1)
      : addDays(start, 7 - ((start.getDay() + 6) % 7))
    const end = next < range.end ? next : range.end
    list.push({ start, end, label: bucket === 'month' ? monthLabel(start) : dayLabel(start) })
    start = end
  }
  return list
}

// Transactions count on their local day. The balance includes everything before the range, so its
// last point is the balance at the end of the period. Japan is 10% of the period's income.
export function moneySeries ({ transactions, range, bucket = 'week' }) {
  const dated = transactions
    .map(transaction => ({ at: toDate(transaction.date), cents: toCents(transaction.amount) }))
    .filter(transaction => transaction.at)
  let balance = dated.filter(transaction => transaction.at < range.start).reduce((sum, transaction) => sum + transaction.cents, 0)
  let income = 0
  let expenses = 0
  const rows = buckets(range, bucket).map(({ start, end, label }) => {
    const inside = dated.filter(transaction => transaction.at >= start && transaction.at < end)
    const bucketIncome = inside.filter(transaction => transaction.cents > 0).reduce((sum, transaction) => sum + transaction.cents, 0)
    const bucketExpenses = inside.filter(transaction => transaction.cents < 0).reduce((sum, transaction) => sum - transaction.cents, 0)
    income += bucketIncome
    expenses += bucketExpenses
    balance += bucketIncome - bucketExpenses
    return { label, income: bucketIncome, expenses: bucketExpenses, balance }
  })
  return {
    buckets: rows.map(row => ({ label: row.label, income: toEuros(row.income), expenses: toEuros(row.expenses), profit: toEuros(row.income - row.expenses) })),
    balanceLine: rows.map(row => ({ label: row.label, balance: toEuros(row.balance) })),
    totals: { income: toEuros(income), expenses: toEuros(expenses), profit: toEuros(income - expenses), balance: toEuros(balance) },
    japan: toEuros(Math.round(income * 0.1))
  }
}
```

```js
// Stock tab: stock value, what runs out first, printed vs sold, and commission figures
import { UNKNOWN_ARTICLE } from '../commissions.js'
import { effectivePrice } from '../pricing.js'
import { toCents, toEuros, toDate, soldUnits } from './common.js'
import { inPeriod } from './period.js'

const DAY_MS = 86_400_000
// "Runs out in" uses the average daily units sold over this many days
export const RECENT_DAYS = 30
const OPEN = ['open', 'printing', 'ready']

const isActive = article => article.active !== false
const categoryOf = (article, categories) => categories.find(category => category.id === article.category) ?? article.expand?.category
const stockOf = article => Math.max(0, Number(article.stock) || 0)

// Σ stock × current price (the article's override, else its category's base price) over active articles
export function stockValue (articles, categories = []) {
  const cents = articles.filter(isActive)
    .reduce((sum, article) => sum + toCents(effectivePrice(article, categoryOf(article, categories))) * stockOf(article), 0)
  return toEuros(cents)
}

// Active articles by days of stock left at the last RECENT_DAYS days' pace, fewest first.
// Articles without a sale in that time are not listed.
export function runsOutSoonest ({ articles, movements, now = new Date(), limit = 5 }) {
  const from = now.getTime() - RECENT_DAYS * DAY_MS
  const sold = new Map()
  for (const movement of movements) {
    const at = toDate(movement.created)
    if (!at || at.getTime() <= from || at > now) continue
    sold.set(movement.article, (sold.get(movement.article) ?? 0) + soldUnits(movement))
  }
  return articles
    .filter(article => isActive(article) && sold.get(article.id) > 0)
    .map((article) => {
      const perDay = sold.get(article.id) / RECENT_DAYS
      return { id: article.id, name: article.name, stock: stockOf(article), days: Math.round(stockOf(article) / perDay) }
    })
    .sort((a, b) => a.days - b.days || a.name.localeCompare(b.name))
    .slice(0, limit)
}

// Units printed and sold per article in the period, busiest first
export function printedVsSold (movements, range, articles = []) {
  const rows = new Map()
  for (const movement of movements) {
    if (!inPeriod(movement.created, range)) continue
    const printed = movement.reason === 'printed' ? Number(movement.change) : 0
    const sold = soldUnits(movement)
    if (!printed && !sold) continue
    const name = articles.find(article => article.id === movement.article)?.name ?? movement.expand?.article?.name ?? UNKNOWN_ARTICLE
    const row = rows.get(movement.article) ?? { id: movement.article, name, printed: 0, sold: 0 }
    row.printed += printed
    row.sold += sold
    rows.set(movement.article, row)
  }
  const list = [...rows.values()].sort((a, b) => b.printed + b.sold - (a.printed + a.sold) || a.name.localeCompare(b.name))
  return {
    rows: list,
    printed: list.reduce((sum, row) => sum + row.printed, 0),
    sold: list.reduce((sum, row) => sum + row.sold, 0)
  }
}

// Open value (open, printing and ready, whenever created), the value delivered in the period and the
// average days from created to delivered for those, to one decimal (null when none was delivered)
export function commissionFigures (commissions, range) {
  const open = commissions.filter(commission => OPEN.includes(commission.status))
  const delivered = commissions.filter(commission => commission.status === 'delivered' && inPeriod(commission.delivered_at, range))
  const spans = delivered
    .map(commission => [toDate(commission.created), toDate(commission.delivered_at)])
    .filter(([created, done]) => created && done)
    .map(([created, done]) => (done - created) / DAY_MS)
  const value = list => toEuros(list.reduce((sum, commission) => sum + toCents(commission.agreed_price), 0))
  return {
    openCount: open.length,
    openValue: value(open),
    deliveredCount: delivered.length,
    deliveredValue: value(delivered),
    averageDays: spans.length ? Math.round(spans.reduce((sum, days) => sum + days, 0) / spans.length * 10) / 10 : null
  }
}
```

```js
import { ref, watch, onMounted, onBeforeUnmount } from 'vue'
import { usePocketBase } from './usePocketBase'
import { useArticles } from './useArticles'
import { useCategories } from './useCategories'
import { useDeals } from './useDeals'
import { useCommissions } from './useCommissions'

const MOVEMENTS = 'stock_movements'
const DAY_MS = 86_400_000
// "Runs out in" needs the last 30 days of movements, whatever the period
const RECENT_DAYS = 30

const empty = () => ({ articles: [], categories: [], deals: [], commissions: [], movements: [], loadedAt: new Date() })
// A collection the server does not have yet (404) or still locks (403) has nothing to report
const orEmpty = promise => promise.catch(error => (error?.status === 403 || error?.status === 404 ? [] : Promise.reject(error)))
const offline = () => typeof navigator !== 'undefined' && !navigator.onLine

// Server records behind the Sales, Market day and Stock tabs: every article (archived ones too, for
// their names) with its category, the categories, deals and commissions, and the stock movements of
// the period plus the last 30 days. `range` is a ref of { start, end }; a new range loads again.
// Offline nothing loads and needsConnection is set; coming back online loads again.
export const useReportData = (range) => {
  const pb = usePocketBase()
  const { listAll } = useArticles()
  const { listCategories } = useCategories()
  const { listDeals } = useDeals()
  const { listCommissions } = useCommissions()

  const data = ref(empty())
  const loading = ref(true)
  const needsConnection = ref(false)
  const error = ref('')
  // Only the latest load may write its answer: one for an earlier period, or from before going offline, is dropped
  let run = 0

  // pb.filter writes a Date as PocketBase's 'YYYY-MM-DD HH:MM:SS.sssZ'
  const movementsFrom = (start, end) => orEmpty(pb.collection(MOVEMENTS).getFullList({
    filter: end
      ? pb.filter('created >= {:start} && created < {:end}', { start, end })
      : pb.filter('created >= {:start}', { start }),
    sort: 'created,id',
    expand: 'article'
  }))

  const load = async () => {
    const current = ++run
    error.value = ''
    if (offline()) {
      needsConnection.value = true
      loading.value = false
      return
    }
    loading.value = true
    const now = new Date()
    const { start, end } = range.value
    try {
      const [articles, categories, deals, commissions, inPeriod, recent] = await Promise.all([
        listAll(),
        listCategories(),
        orEmpty(listDeals()),
        orEmpty(listCommissions()),
        movementsFrom(start, end),
        movementsFrom(new Date(now.getTime() - RECENT_DAYS * DAY_MS))
      ])
      if (current !== run) return
      // The two windows overlap: each movement counts once
      const movements = [...new Map([...inPeriod, ...recent].map(movement => [movement.id, movement])).values()]
      data.value = { articles, categories, deals, commissions, movements, loadedAt: now }
      needsConnection.value = false
    } catch (err) {
      if (current !== run) return
      if (offline() || err?.status === 0) needsConnection.value = true
      else error.value = 'Could not load the report. Check your connection and try again.'
    } finally {
      if (current === run) loading.value = false
    }
  }

  const goneOffline = () => {
    run++
    needsConnection.value = true
    loading.value = false
  }

  watch(() => `${range.value.start.getTime()}-${range.value.end.getTime()}`, load)

  onMounted(() => {
    window.addEventListener('online', load)
    window.addEventListener('offline', goneOffline)
    load()
  })

  onBeforeUnmount(() => {
    window.removeEventListener('online', load)
    window.removeEventListener('offline', goneOffline)
  })

  return { data, loading, needsConnection, error, reload: load }
}
```

```js
// CSV of the current report tab's table. Money is written in euros with two decimals and a dot.
import { csvField } from '../transactions.js'
import { toCents } from './common.js'

const money = value => (toCents(value) / 100).toFixed(2)
const hour = value => `${String(value).padStart(2, '0')}:00`

export const toCsv = ({ headers, rows }) => [headers, ...rows].map(row => row.map(csvField).join(',')).join('\n')

// figures: sales → salesSummary(); market → { day, report: dayReport() | null };
// money → moneySeries(); stock → { printed: printedVsSold() }
export function reportTable (tab, figures) {
  if (tab === 'sales') {
    return {
      headers: ['Article', 'Units', 'Revenue'],
      rows: figures.topArticles.map(row => [row.name, row.units, money(row.revenue)])
    }
  }
  if (tab === 'market') {
    return {
      headers: ['Day', 'Hour', 'Takings'],
      rows: figures.report ? figures.report.perHour.map((takings, index) => [figures.day, hour(index), money(takings)]) : []
    }
  }
  if (tab === 'money') {
    return {
      headers: ['Period', 'Income', 'Expenses', 'Profit', 'Balance'],
      rows: figures.buckets.map((bucket, index) => [bucket.label, money(bucket.income), money(bucket.expenses), money(bucket.profit), money(figures.balanceLine[index].balance)])
    }
  }
  if (tab === 'stock') {
    return {
      headers: ['Article', 'Printed', 'Sold'],
      rows: figures.printed.rows.map(row => [row.name, row.printed, row.sold])
    }
  }
  throw new Error(`Unknown report: ${tab}`)
}
```

Create `utils/download.js`:

```js
// Hands the browser a text file to save: a temporary link with `download`, then the object URL is released
export function downloadText (filename, text, type = 'text/plain') {
  const url = URL.createObjectURL(new Blob([text], { type }))
  const link = document.createElement('a')
  link.href = url
  link.download = filename
  document.body.appendChild(link)
  link.click()
  document.body.removeChild(link)
  URL.revokeObjectURL(url)
}
```
